## Deliberate design-lock changes

The owner's blueprint explicitly supersedes the earlier five-link header, three hero actions, four proof-rail items, four visitor choices, and method/partner section rules. The new arrival has the exact specified supporting copy and two links. Home order: arrival, three visitor paths, Nelson evidence, founder, Opportunity Plan, invitation. The approved image SHA-256 remains `a1de24393eda3bf7ca0ece805a96b71554b7006aee0fcede5d7c41554d8409a3`.

New `/tools` is registered in the existing route type, Pegasus route map, mounted Landing component, shared SPA registry, SEO/sitemap map, and keyboard/route checks. It offers Strategy Lab, browser-saved work, and request-based Property Review. No paid product, checkout, price, or download is invented.

Navigation search retains the former supporting destinations. Theme settings move inside the menu. Mobile uses the same destinations, a Real Estate disclosure, search, appearance, human contact, and Peggy. Escape/focus containment/restoration and scroll locking are retained; background content is inert while the modal is open.

Navigation continuity now has one application-level owner. Ordinary path changes start at the heading; query-only changes preserve position; Back/Forward are left to browser restoration. Deep-link targets are resolved after lazy rendering and offset by the actual header height. No personal-data cache or global store is added.
