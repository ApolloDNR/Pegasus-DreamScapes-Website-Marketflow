## 1. Executive Summary

Build the public website for Pegasus Dreamscapes Corp.

This website must present Pegasus Dreamscapes as a serious, premium, founder-led real estate investment and execution company.

The website is not a generic realtor website. It is not a wholesaler website. It is not a fantasy architecture website. It is not a SaaS product website first. It is not a fake institutional developer website.

The website is a deal intake and routing system.

Pegasus Dreamscapes receives property situations, off-market leads, distressed owner inquiries, deal finder submissions, buyer interest, capital partner inquiries, vendor/operator interest, referral partner inquiries, and strategy review requests. The website must route visitors into the correct lane.

The public operating model is:

**Acquisitions → Development → Dispositions → Asset Management**

The support tool layer is:

**Strategy Lab → MarketFlow → PeggyAI → Pegasus HQ**

The long-term vision is:

**The Pegasus Standard** — a future living standard inspired by Hellenic Modern / Classical Mediterranean architecture: pale limestone, ivory plaster, travertine, simplified Greek columns, courtyards, colonnades, fountains, olive trees, cypress trees, open air, calm, beauty, and human flourishing.

The website must balance two truths:

1. **Current reality:** Pegasus is an early-stage real estate operating company with founder-led execution, one real completed value-add case study, active deal-building ambitions, and licensed real estate representation available through Apollo/Keller Williams where appropriate.
2. **Long-term vision:** Pegasus is building toward beautiful, durable, human-centered homes, neighborhoods, and communities.

The website must be honest, premium, functional, elegant, and launchable.

## 8. Visual Design System

### 8.1 Overall look

Premium real estate operator with classical architectural soul.

The website should feel like a dark navy strategy office, warm cream stone gallery, bronze/copper Pegasus brand, architectural blueprint system, Hellenic Modern atmosphere, and founder-led real estate execution.

### 8.2 Color palette

Primary dark: deep navy / near-black navy. Examples: `#07111F`, `#0B1624`, `#101820`.

Secondary dark: charcoal. Example: `#171717`.

Warm light: ivory / limestone / warm cream. Examples: `#F4EFE6`, `#E8DED0`, `#D9CBB9`.

Accent: copper / bronze. Examples: `#B47645`, `#C8915B`, `#8B5A36`.

Signal accent: muted olive / cypress green. Examples: `#4F5B43`, `#657153`.

Avoid bright gold, cheap blue, random colorful icons, pure white backgrounds everywhere, and overly saturated gradients.

### 8.3 Typography

Use a premium editorial pairing: serif for headlines and clean sans-serif for body/UI.

Style: large elegant headlines, generous spacing, short paragraphs, no cramped sections, and no generic startup font feel.

### 8.4 UI style

Cards: rounded but not bubbly, subtle borders, bronze/copper thin dividers, soft shadows only if needed, cream cards on navy or navy cards on cream.

Forms: elegant, calm, multi-step, readable labels, progress indicator, save/continue if possible, confirmation page after submit.

Buttons: primary bronze/copper on navy or navy on cream; secondary outline bronze/copper. No neon or oversized playful buttons.

Icons: thin-line icons in bronze/cream/navy only. Use property, map pin, blueprint, hammer, exit arrow, key, network nodes, compass, shield, document, column, and fountain.
