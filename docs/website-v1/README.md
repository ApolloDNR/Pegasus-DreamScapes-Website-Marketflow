# Pegasus Dreamscapes Public Website v1

This folder is the source-of-truth planning package for the Pegasus Dreamscapes Corp. public website rebuild.

## Locked website direction

**Core promise:** Complex property. Structured opportunity.

**Primary CTA:** Submit a Property

**Secondary CTA:** Request a Strategy Review

**Company:** Pegasus Dreamscapes Corp.

**Tagline:** Dream it. Build it. Live it.

**Public corporate division line:** Development • Investments • Systems

**Website operating model:** Acquisitions → Development → Dispositions → Asset Management

**Support tools:** Strategy Lab → MarketFlow → PeggyAI → Pegasus HQ

**Long-term visual standard:** The Pegasus Standard — Hellenic Modern / Classical Mediterranean real estate: pale limestone, ivory plaster, travertine, simplified Greek columns, colonnades, courtyards, olive trees, cypress trees, fountains, water, fire, calm, beauty, durability, and human flourishing.

## Files

- `PEGASUS_PUBLIC_WEBSITE_PRD_V1.md` — Full product requirements document and website master plan.

- `ROUTING_FORMS_AND_DATA_SCHEMA.md` — Visitor routing, intake form flow, opportunity statuses, and database schema guidance.
- `COPY_DECK_V1.md` — Locked first-pass homepage/page copy and CTA language.

## Non-negotiable framing

This website is the front door to Pegasus Dreamscapes. It must present Pegasus as a real estate investment, development, strategy, and execution company. It must not present Pegasus as a fake giant developer, generic realtor site, wholesaler site, fantasy architecture brand, or SaaS dashboard-first product.

The future architecture vision belongs primarily in the `The Pegasus Standard` / Vision sections. The current operating website must remain grounded in property review, acquisitions, development, dispositions, asset management, and founder-led real estate strategy.
