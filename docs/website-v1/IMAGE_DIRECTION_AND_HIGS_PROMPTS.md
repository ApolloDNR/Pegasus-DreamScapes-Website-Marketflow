# Pegasus Website Image Direction + HIGS Prompt Pack

This document is the image generation and art direction source of truth for Pegasus Dreamscapes Public Website v1.

## 1. Visual North Star

Pegasus Dreamscapes’ long-term architecture direction is:

**Hellenic Modern / Classical Mediterranean**

Core visual elements:

- Pale limestone
- Ivory plaster
- Travertine
- Simplified Greek-style fluted columns
- Flat rooflines
- Colonnades
- Courtyards
- Pergolas
- Olive trees
- Cypress trees
- Fountains
- Water channels
- Fire bowls
- Warm evening lighting
- Cool stone
- Open-air living
- Calm luxury
- Human-centered architecture

This is not Tuscan, not Spanish Revival, not American neoclassical, not plantation, not McMansion classical, and not a fantasy palace.

The style should feel grounded, premium, realistic, calm, durable, fresh, and architectural.

The site must use three image categories.

Cropped Hellenic Modern architectural details.

Examples:

- Stone entry
- Columns

- Courtyard shadow

### Category C — Future Vision

Use for:

- The Pegasus Standard page
- Homepage Vision section

Visual style:

Full Hellenic Modern / Classical Mediterranean homes and communities.

Examples:

- Limestone homes
- Courtyards
- Colonnades
- Fountains

- Warm evening light

Important:

Do not use future vision imagery in a way that implies current active inventory or current active developments.

## 3. Global HIGS Prompt Doctrine

Use this as the base doctrine for all generated images:

```text
Pegasus Dreamscapes visual north star: Hellenic Modern / Classical Mediterranean real estate. Pale limestone, ivory plaster, travertine, simplified Greek-style fluted columns, flat rooflines, colonnades, courtyards, pergolas, olive trees, cypress trees, fountains, water channels, fire bowls, warm evening lighting, cool stone, open-air living, calm luxury, human-centered architecture.

The images must feel cinematic, realistic, premium, restrained, and architectural. No fantasy palaces. No American neoclassical mansions. No Tuscan villas. No Spanish Revival. No fake resort branding. No impossible AI architecture. No visible text. No signs. No people unless specifically requested. No logos.

Use the Hellenic Modern imagery as the long-term Pegasus Standard, while keeping the current website grounded as a real estate investment and execution company.
```

## 6. Image Rules

Do:

- Use cinematic, realistic, architectural imagery.
- Use dark navy overlays where copy needs readability.
- Use actual HTML text for all important labels.
- Compress and optimize all images.
- Lazy-load non-hero images.
- Use real Apollo headshot for Apollo.
- Use real case study photos for Nelson if available.

Do not:

- Do not use fake readable text inside AI images.
- Do not use visible logos or signs.
- Do not use fake active Pegasus inventory.
- Do not use fake before/after project imagery.
- Do not use fantasy architecture.
- Do not use Tuscan, Spanish Revival, American neoclassical, plantation, Georgian, or McMansion classical visuals.
- Do not use generic stock handshakes, cash piles, foreclosure panic imagery, or people crying in front of houses.
- Do not make future vision imagery look like current inventory.
